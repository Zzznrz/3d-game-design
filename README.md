# SDC 3D Game

Unity 3D group project for CS583. This repository currently contains the initial Universal 3D (URP) project; gameplay is not implemented yet.

## Open the project

1. Install Unity Hub and Unity **6000.5.10f1**.
2. Clone this repository to your own computer.
3. In Unity Hub, choose **Add → Add project from disk** and select the repository folder containing `Assets`, `Packages`, and `ProjectSettings`.
4. Wait for package installation and asset import, then open `Assets/Scenes/SampleScene.unity`.

## Collaboration

- Use the same Unity Editor version: **6000.5.10f1**.
- Pull the latest changes before starting work. Use a feature branch and pull request for each task.
- Coordinate before editing the same scene or prefab.
- Commit asset files together with their `.meta` files; move and rename assets inside Unity.
- Do not commit `Library`, `Temp`, `Logs`, or `UserSettings`.
- Each member should make commits using their own GitHub identity so team contributions are recorded.
