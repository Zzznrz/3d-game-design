# Game Name: BUST OR BOOM

Unity 3D group project for CS583. This repository currently contains the initial Universal 3D (URP) project; gameplay is not implemented yet.

## Open the project

1. Install Unity Hub and Unity **6000.5.9f1**.
2. Clone this repository to your own computer.
3. In Unity Hub, choose **Add → Add project from disk** and select the repository folder containing `Assets`, `Packages`, and `ProjectSettings`.
4. Wait for package installation and asset import, then open `Assets/Scenes/SampleScene.unity`.

## Game Plan
This is a third-person 3D Extraction Shooter game: Players enter the map to collect resources, engage in battles with enemies, and take away the items they obtain after successfully escaping. The game features high risks and high rewards. Before entering the game, players will choose the items or weapons to bring into the game. If they successfully escape, all of them can be kept. If they die, all weapons, items, and resources will disappear.
